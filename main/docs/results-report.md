# Báo cáo kết quả thực nghiệm

## 1. Giới thiệu
Mô tả mục tiêu, các phương pháp so sánh.

## 2. Cấu hình thực nghiệm
- Phần cứng, phần mềm, tham số thử nghiệm.

## 3. Kết quả hiệu năng
- Biểu đồ, bảng phân tích latency, error rate, resource usage.

## 4. Chất lượng phân bổ
- Tỉ lệ thành công, nguyện vọng 1, sinh viên năm cuối.

## 5. Tính công bằng
- Chỉ số Jain, phân phối theo nhóm.

## 6. Độ bền vững
- Kết quả khi gặp sự cố.

## 7. Kết luận
